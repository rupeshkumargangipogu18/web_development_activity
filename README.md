## Project 1 – FITZONE: Gym Website

### Description

FITZONE is a front-end website for a gym and fitness centre. It presents workout options, trainer categories, membership prices, facilities, a weekly class schedule, and a registration form. Visitors can use the navigation links to move between the main sections.

### Objectives

- Organise gym information into clearly labelled webpage sections.
- Present workout programmes and trainer categories.
- Display membership plans and monthly prices.
- Show gym facilities and a weekly class schedule.
- Provide a front-end registration form for visitor details.

### Features

- Header with FITZONE branding and section navigation.
- Hero section with the message **“BUILD YOUR BEST BODY”** and a **“Join Now”** button.
- Workout programme cards:
  - Strength Training
  - Cardio Fitness
  - Yoga & Flexibility
- Trainer category cards:
  - Strength Coach
  - Cardio Coach
  - Yoga Instructor
- Membership plans:
  - Basic – 999/- per month
  - Standard – 1,499/- per month
  - Premium – 2,499/- per month
- Facilities list: Modern Equipment, Locker Rooms, and Personal Training.
- Weekly class schedule: Monday – Yoga, Wednesday – Cardio, Friday – Strength.
- Registration form with name, email, phone, an additional text field, and a membership dropdown.
- CSS card hover effects, button hover effects, smooth in-page scrolling, and a media query for smaller screens.

### Technologies

- HTML5
- CSS3 (CSS Grid, Flexbox, hover effects, and a media query)

## Project 2 – Restaurant Theme: Foodie's Corner

### Description

Foodie's Corner is a simple food menu webpage that displays a selection of food and drink items with photographs, names, and prices. It uses a warm colour theme and a flexible card-based layout to make the menu easy to view.

### Objectives

- Present menu items and prices in one place.
- Use food photographs to help visitors identify each item.
- Arrange menu information in clear, consistently styled cards.

### Features

- Header with the title **“Foodie's Corner”** and the tagline **“Delicious food,Happy Mood”**.
- **“Our special menu”** heading.
- Four menu cards:
  - Veg pizza – 199/-
  - Burger – 99/-
  - Biryani – 300/-
  - Milk shake – 89/-
- Food photographs displayed within the menu cards.
- Flexible layout that can wrap cards when the available width is smaller.
- Rounded card corners, shadows, and a hover scaling effect.
- Footer message: **“Thank you ! Visit Again 💖”**.

### Technologies

- HTML5
- CSS3 (Flexbox, image sizing with `object-fit`, card styling, and hover effects)

## Project 3 – Student Dashboard: EduPortal

### Description

EduPortal is a student academic dashboard website designed to present academic information in one place. The project uses HTML pages connected to a shared CSS stylesheet. It includes a dashboard overview and separate pages for profile information, semester results, attendance, subjects, examinations, and announcements.

### Objectives

- Provide a dashboard-style overview of academic information.
- Display student profile and academic status details.
- Present grades, credits, and SGPA in a table.
- Show subject-wise attendance percentages using progress bars.
- List enrolled subjects and their course codes and credits.
- Display examination dates and times.
- Present academic announcements and reminders.
- Provide sidebar navigation between dashboard sections and pages.

### Features

- Dark navy sidebar with links for Dashboard, My Profile, Semester Results, Attendance, Subjects, Examination, and Announcements.
- Dashboard summary cards showing:
  - Current CGPA: 8.6/10
  - Overall attendance: 87%
  - Total subjects: 6
  - Credits earned: 24
- Semester results table with subject names, grades, credits, and an SGPA value of 8.6.
- Subject attendance values with coloured progress bars:
  - Mathematics III – 92%
  - Data Structures – 85%
  - Digital Logic – 78%
  - Python Programming – 90%
- Subject cards for Data Structures, Python Programming, Mathematics III, and Digital Logic.
- Examination timetable with subject, date, and time.
- Announcements for Internal Examination, Attendance Reminder, and Assignment Submission.
- Shared CSS styling and a responsive rule for screens up to 650 pixels wide.

### Technologies

- HTML5
- CSS3 (Flexbox, CSS Grid, tables, progress-bar styling, and responsive media query)

## How to Run

These are front-end HTML and CSS projects. No build process or server-side setup is documented as required.

1. Download or clone this repository:
   ```bash
   git clone <your-repository-url>
   ```
2. Open the downloaded project folder on your computer.
3. Locate the relevant project's main HTML file.
4. Make sure its linked CSS file and any required image assets are kept in the expected relative locations.
5. Double-click the HTML file, or open it in a web browser.

- Linking multiple HTML pages to a shared stylesheet.
